# Screenshot slots

The site shows HTML recreations of Perch until real captures arrive. To swap one in:

1. Capture the scene on a 5K (5120 x 2880) or 4K screen at 100% zoom, in dark mode with the Owl Night theme.
2. Crop to the size below, export as WebP (quality 85), and save it here under the exact name.
3. Add the name to `shots.json`, for example `{ "ready": ["notch-open.webp"] }`.
4. Check it in both themes: the capture covers the recreation in both.

| File | Crop (px) | What it shows | Used in |
|---|---|---|---|
| `notch-open.webp` | 2400 x 2400 | The notch opened: clock with second time zone, music with album art and visualizer, weather, CPU/RAM/GPU/network widgets. Wallpaper visible around it. | Chapter 01 stage |
| `dock-preview.webp` | 2400 x 2400 | The dock with the cursor on one icon (magnified), a window preview of two windows open above it, drives pinned. | Chapter 02 stage |
| `start-menu.webp` | 2400 x 2400 | The Modern Start menu with `12*7` typed in search and the calculator answer showing. | Chapter 03 stage |
| `weather-hourly.webp` | 2400 x 2400 | The notch's weather view with the hour-by-hour forecast. | Chapter 04 stage |
| `notch-designs.webp` | 2400 x 2400 | A collage of the 12 notch designs on one wallpaper. | Chapter 05 stage |
