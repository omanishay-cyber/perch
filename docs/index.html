The Windows taskbar,reconsidered.

Perch swaps the taskbar for a dock that magnifies under your cursor, puts a live notch at the top of your screen, and brings a Start menu you can style six ways.

Download for Windows See how it works

Version 1.1 · Free · Windows 11 and Windows 10 22H2

01, The notch

A notch that knows things.

The empty strip at the top of your screen finally earns its place. Hover it and it opens: the time, the weather, your music and how hard your PC is working.

  • Time. Clock, a second time zone, calendar, timers and a stopwatch.
  • Music. Album art, controls and a visualizer that moves with the song.
  • Your PC. Live CPU, RAM, GPU, disk, network, volume and battery.
  • Quick controls. Wi-Fi, Bluetooth, sound, notifications, clipboard history, a quick note and the power menu.
02, The dock

Aim, and it meets you.

Icons grow under your cursor, so the one you are reaching for is always the largest. Hover an open app to see its windows before you switch.

  • Pins. Apps, folders and drives, with the Recycle Bin at the end.
  • Previews. Live window previews; close a window right from its preview.
  • Full screen. Hidden over full-screen apps until you press Start, the same rule the taskbar follows.
03, The Start menu

Your Start menu, six ways.

Modern, Windows 11, Windows 10 tiles, Down Aero, Windows 11X or Windows 7. Search is as quick as the one in Windows, and it does sums too.

  • Search. Apps, files, Settings pages, a calculator and unit conversions.
  • Pins. Jump lists, pinned folders and a strip of widgets.
  • Suggestions. What you open in the morning differs from the evening, and so do they.
  • Keyboard. Every part works without a mouse.
04, Weather

Weather that looks outside.

The sky right now sits in the notch. Open it for the hour-by-hour forecast. The sky on this page follows your own clock: come back tonight and it will be dark.

05, The looks

Twelve notches. Two looks.

Pick one of twelve notch designs, then a look: Simple or Graphics. Light and dark follow your Windows setting, on every screen size and scaling level, touch screens included.

Questions, answered.

Is Perch free?

Yes. Perch costs nothing, at home or at work. The licence lets you use it on any PC you own or manage; it does not let you copy, change, share or sell it.

Which versions of Windows does Perch run on?

Windows 11 and Windows 10 version 22H2. Older versions of Windows 10 are not supported. To check yours, press Win + R, type winver and press Enter.

What happens over full-screen games and videos?

The dock stays hidden over full-screen apps and shows up only when you press the Start key, the same rule the Windows taskbar follows.

How do updates work?

Each release on GitHub carries a small file called latest.json. Perch reads it to learn whether a newer version exists and offers you the update. Every installer is signed, and Perch refuses an update whose signature does not match.

Does Perch collect my data?

No personal data. Perch counts installs and daily use anonymously by fetching tiny files from its GitHub releases. GitHub counts the downloads; nothing else is sent.

Does Perch work with touch screens and high-DPI displays?

Yes. Perch works on every screen size and scaling level, and on touch screens.

How do I remove Perch?

Open Settings, then Apps, then Installed apps. Find Perch and choose Uninstall.

Is the source code available?

No. The source code is private. The public GitHub repository holds the installers, release notes, the update file and the licence.
