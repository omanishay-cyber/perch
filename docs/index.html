Three things you look at all day. All three, rebuilt.

Perch sits on top of Windows and replaces the parts you see most. The taskbar becomes a dock. The empty strip at the top of your screen becomes a notch that shows the time, the weather, your music and how your PC is doing. The Start button opens a menu of its own.

05

Every icon, one click.

One click changes every icon in the dock and the Start menu. Each pack is made from each app's own icon, so it covers every app you have. System icons puts it all back.

Load your own.

Point Perch at a folder of PNG or ICO files, or a Resource Redirect pack. Perch reads them as pictures, runs nothing, and tells you how many icons it matched.

Apply to Windows too.

Optional, and off by default. Folders, drives, This PC, the Recycle Bin, Network and common file types in File Explorer follow your pack, through Windows' own settings. No system file is touched, and Put Windows icons back restores every original exactly.

Everything in 1.1.

The notch
  • Controls panel: Wi-Fi, Bluetooth, dock and notch modes, volume, brightness and a row of switches
  • Switches: Camera off, Do not disturb, Mute mic, Dark mode, Location; right-click one for its Windows Settings page
  • Status widgets: Weather, Battery, CPU, RAM, GPU, VRAM, Disk, Net, Volume, Brightness, Microphone, Date; drag each to the left or right
  • Clock: 12 or 24 hours, seconds if you like, your own date pattern, a second time zone
  • Weather: now, and hour by hour, for any city, in °F or °C
  • Calendar: a month grid, and calendar links that put a dot on days with events
  • Timer: 5, 15, 25 and 50 minute presets, a chime, and a thin line round the notch that fills as it runs
  • Stopwatch: with laps
  • Music: album art, controls, seeking and a choice of sources; Classic and Compact layouts
  • Five visualizers and an ambient glow from the album art
  • Live lyrics: the line being sung, on the closed notch
  • Media exclusions: apps or sites that never take over the notch
Notch views and alerts
  • Wi-Fi: scan, connect, disconnect, forget
  • Bluetooth: pair, connect, disconnect, see battery levels
  • Sound: pick the output, set each app's volume, mute each app
  • Clipboard: history with pins and pictures, and a quick note that saves itself
  • Notifications: recent Windows notifications grouped by app, with a count on the notch
  • Power: Lock, Sleep, Hibernate, Shut down, Full shut down, Restart; the risky ones ask for a second click
  • Shelf: drag files onto the notch and pick them up later
  • Alerts: Caps Lock, Num Lock, charging, low battery, USB drives with Open and Eject, Bluetooth devices, copied pictures, a new version with Update
  • Privacy dots: orange for the microphone, green for the camera; point at one to see which app
  • Game strip: CPU, GPU and RAM over a full-screen game
  • Hide or show with a shortcut (Ctrl+Alt+D by default), or automatically over full-screen apps
  • Peek: reveal it as soon as the pointer touches the top edge, or after a delay you set
The dock
  • Magnification: set how big the icon under the pointer grows and how many beside it grow too
  • Live previews of every window on hover
  • Three styles: Attached, Floating, Strip; a choice of edge shapes where it meets the screen
  • Extras: fixed, removable and network drives, special folders, any folder you add, the Recycle Bin
  • USB sticks show on the dock while they are in, with Eject on a right-click
  • Buttons: Search, Task View and Show desktop, each one optional
  • Bounce when an app opens, higher when it needs you
  • Unread badges on an app's icon
  • Win+1 to Win+9 open pinned apps
  • Smart hide: steps away from maximized windows and full-screen apps, and comes back after
  • Full width when a window is maximized, or always; Icons only; a divider before unpinned apps
  • Lock icons so nothing gets dragged off by accident
  • Your own Start button picture, and a Show desktop corner

  • Suggested now: the apps you open at this hour, weekdays apart from weekends; old habits fade
  • Most used, Recommended files and newly installed apps

08

Three steps, then it's there.

  1. Download

    Perch-Setup.exe, straight from the GitHub release page. Windows 11, or Windows 10 version 22H2.

  2. Run it

    If SmartScreen shows "Windows protected your PC", click More info, then Run anyway. It warns about apps it has not seen many times yet.

  3. Look up, look down

    Perch takes over the top and bottom of the screen when it starts. Everything else is in its Settings, with a search box.

Updates

When Perch starts and every 6 hours, it reads a small file called latest.json from its release page, whatever the Auto update switch says. When there is a new version the notch says so and waits for you to press Update. With Auto update on, which is off until you turn it on, it installs by itself with no question, an hour after the release. Perch refuses any update whose signature does not match.

What goes over the internet

  • A counter. Once after install and once a day, Perch downloads a tiny file from its release page. GitHub's download count is the count. No id, no settings, no files go with it. Settings, About, Privacy turns it off.
  • The update check, at start and every 6 hours.
  • The weather, from Open-Meteo. A fresh install finds its city from your IP address through ipapi.co, or ip-api.com if that fails, until you pick one.
  • Live lyrics, off until you turn them on, then looked up on lrclib.net once per song.
09

Questions.

Is Perch free?

Yes. Perch costs nothing, at home or at work. The licence lets you use it; it does not let you copy, change, share or sell it.

Which versions of Windows does Perch run on?

Windows 11 and Windows 10 version 22H2. Older versions of Windows 10 are not supported. To check yours, press Win + R, type winver and press Enter.

Do my apps and files change?

No. Your apps, files and settings stay where they are. Perch only changes how you reach them. Quit or uninstall Perch and the Windows taskbar and Start menu are back.

Do Windows keyboard shortcuts still work?

Yes. The Windows key on its own and Ctrl+Esc open Perch's Start menu. Every Win+key shortcut keeps working, and you can hand the key back to Windows Start in Settings.

What happens over full-screen games and videos?

The dock stays hidden over full-screen apps and shows up only when you press the Start key, the same rule the Windows taskbar follows. The notch steps away too, and you can turn on a small strip with CPU, GPU and RAM over games.

Why does Windows show a SmartScreen warning?

SmartScreen warns about apps it has not seen many times yet. Click More info, then Run anyway. The file comes straight from Perch's GitHub release page.

Can I use my own icons?

Yes. Point Perch at a folder of PNG or ICO files, or a Resource Redirect pack. Perch reads them as pictures, runs nothing, and tells you how many icons it matched.

Do icon packs change Windows?

Only if you ask. A pack changes what Perch draws. Apply to Windows too is off by default and reaches folders, drives, This PC, the Recycle Bin, Network and common file types in File Explorer, through Windows' own settings. Put Windows icons back restores every original exactly, and so does uninstalling Perch. Documents, Downloads and Pictures in Explorer's side panel keep their stock icons, as do apps' own toolbars and Settings.

How do updates work?

When Perch starts and every 6 hours, it reads a small file called latest.json from its GitHub release page, whatever the Auto update switch says. When a new version is out, the notch says so and waits: press Update and Perch installs it and restarts. With Auto update on, which is off until you turn it on, a new version installs by itself with no question once it is an hour old. Perch refuses an update whose signature does not match.

Does Perch collect my data?

No personal data. Once after install and once a day, Perch downloads a tiny counter file from its release page, and GitHub's download count is the count. No id, no settings, no files are sent. Settings, About, Privacy, Count this install anonymously turns it off.

What else goes over the internet?

The update check above. The weather, from Open-Meteo. A fresh install finds its city from your IP address through ipapi.co, or ip-api.com if that fails, until you pick a city yourself. Live lyrics, off until you turn them on, then look up each song on lrclib.net. Web searches you choose open in your browser. That is all.

Does Perch work with touch screens and high-DPI displays?

Yes. Perch works on every screen size and scaling level, and on touch screens.

How do I remove Perch?

Open Settings, then Apps, then Installed apps. Find Perch and choose Uninstall.

Is the source code available?

No. The source code is private. The public GitHub repository holds the installers, release notes, the update file and the licence.

Something is broken. Where do I tell you?

Open a new issue on GitHub and pick the form that fits. A screenshot helps more than anything else. Settings, About, Report a bug fills in your Perch version and Windows build for you.
